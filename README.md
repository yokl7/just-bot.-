# بوت مراقبة شعب جامعة التكنولوجيا (JUST)

## الفكرة
بوت تيليجرام تفاعلي:
`/start` → يختار المستخدم الفصل الدراسي ثم الكلية ثم القسم (أزرار) →
البوت يبعت جدول الشعب مرقّم → المستخدم يرد برقم السطر →
البوت يراقبها بالخلفية ويبعت تنبيه لما تصير "مفتوحة".

## قبل الرفع: جرّب محليًا (اختياري بس مفيد)
```bash
cd just_bot
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
export BOT_TOKEN="التوكن_تبعك"
python bot.py
```
لو اشتغل صح، جرب `/start` على البوت من تيليجرام.

⚠️ **مهم جدًا**: كود `scraper.py` مبني على افتراض ترتيب معيّن لعناصر
الفلاتر بموقع الجامعة (فصل، كلية، قسم، حالة). لو ما ظبطت النتائج،
شغّل هاد الأمر وشوف شو بيطبع، وعدّل الأرقام `SELECT_*` بأول
`scraper.py` حسب الترتيب الصحيح:
```bash
python scraper.py
```

## الرفع على Render (نسخة دائمة الشغل)

1. اعمل حساب على https://render.com (فيه تسجيل بجيميل مباشرة).
2. اعمل حساب مجاني على https://github.com (لو ما عندك واحد). بعدين اعمل
   **repository** جديد (زر New بالصفحة الرئيسية)، أعطيه أي اسم (مثلاً
   `just-bot`)، واختار Public أو Private مش فارق.
   بعد ما يتعمل الـ repo، بيوريك زر **"Add file → Upload files"** —
   اضغط عليه وارفع **الملفات الخمسة نفسها** يلي عندك بجهازك (يلي حملناها
   قبل شوي): `bot.py`, `scraper.py`, `requirements.txt`, `build.sh`,
   `README.md` — كلها مع بعض دفعة وحدة، مباشرة جوا الـ repo (مش داخل
   مجلد فرعي اسمه just_bot). بعد الرفع اضغط **Commit changes**.
3. بـ Render: **New → Web Service** → اختار الـ repo.
4. الإعدادات:
   - **Build Command**: `bash build.sh`
   - **Start Command**: `python bot.py`
   - **Instance Type**: Free
5. تحت **Environment Variables** ضيف:
   - `BOT_TOKEN` = التوكن يلي أخدته من BotFather
   - `WEBHOOK_URL` = رابط السيرفس يلي رح يعطيك ياه Render بعد أول Deploy
     (شكله `https://your-app-name.onrender.com`) — ضيفه بعد أول نشر، وبعدين
     اعمل Manual Deploy مرة ثانية عشان يقرأه.
6. اضغط **Create Web Service**، وانتظر لحد ما يخلص البناء (دقيقتين-٣).

## عشان يضل شغال دايمًا (خطة Render المجانية بتنام بعد ١٥ دقيقة بدون طلبات)
اعمل حساب مجاني على https://uptimerobot.com، وضيف Monitor نوعه HTTP(s)
على رابط السيرفس تبعك (نفس رابط WEBHOOK_URL)، يفحصه كل ٥ دقايق. هيك
السيرفس بيضل صاحي وما بينام.

## أوامر البوت
- `/start` — يبدأ اختيار الفصل/الكلية/القسم ومراقبة شعبة جديدة
- `/mywatches` — يعرض الشعب يلي عم تراقبها حاليًا
- `/stop` — يوقف كل المراقبات

## ملاحظات
- الفحص بيصير كل ٢٠-٣٥ ثانية (فاصل عشوائي) لتفادي حظر الموقع.
- المراقبة بتوقف تلقائيًا بعد ما تبعث تنبيه "الشعبة فتحت" (تقدر تشيل هاد
  الشرط بـ `bot.py` بدالة `check_one_watch` لو بدك يستمر يراقب حتى بعد
  ما تفتح، مثلاً عشان يتابع لو رجعت انسدت).
- لو الموقع غيّر شكله (فلاتر جديدة/أعمدة جديدة)، شغّل `python scraper.py`
  محليًا لتشوف ترتيب العناصر الجديد وتعدّل `scraper.py`.
